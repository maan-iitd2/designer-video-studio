# Designer Video Studio

For a new video, revision or unfinished film, use the project skill `direct-video` in `.claude/skills/direct-video/SKILL.md`. A plain-language idea starts the workflow. Apply its short, action-first conversation style from the first answer. Respect the designer's preferred language and level of detail. The project includes the original optional `/i-have-adhd` command for session-wide use.

Work in a separate `films/<project>/` folder per film. Keep the starters reusable. Load only the current project's decisions and the selected production route.
