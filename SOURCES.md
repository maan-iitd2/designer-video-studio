# Sources included in the handoff

## Downloaded shot collections

The [local catalog](library/index.html) indexes 803 entries. The 150 Shotcraft variants belong to 124 recipes. Herk cards and HyperFrames components are individual building blocks. Nine HyperFrames entries are full example sequences. Each entry has a stable studio ID and a local source path.

| Collection | Included material | Source snapshot |
|---|---|---|
| Herk Edit Kit | 106 Vox and 300 Kallaway editable HTML cards, style tokens, contact sheets, design notes and upstream notices. Example branding belongs to its owners. | [Source](https://github.com/nateherkai/herk-edit-kit/tree/10511e5af86fc47756ea89803b397422e2d89284/style-library) · [License](library/herk-edit-kit/LICENSE) |
| Video Shotcraft | 124 recipes, 150 MP4 examples, demo components, shared fixtures, textures and the Remotion project template. | [Source](https://github.com/Vincentwei1021/video-shotcraft/tree/59f3e9b9e936ff2bce0e18446226d770a3f2f61f) · [Preview release](https://github.com/Vincentwei1021/video-shotcraft/releases/tag/gallery-media) · [License](library/video-shotcraft/LICENSE) |
| HyperFrames | 238 editable components and nine example folders, including compositions, variables and registry manifests. Some demos use external assets. | [Source](https://github.com/heygen-com/hyperframes/tree/a4d96cdb312ee2c5647ad3ecc2bd7b6cdb49aeb5/registry) · [License](library/hyperframes/LICENSE) |

The catalog includes 751 local preview images. The other entries link to the publisher's example. Rights to individual fonts, music, footage and brand material follow their respective owners and notices. Prompt Motion is linked for inspiration in the direction guide.

## Studio starters and conversation skills

- The optional **i-have-adhd** Claude Code command and its MIT license are bundled from commit `1ecea1993b7fce257ffbd686c070948b5e07eda6`. The video director applies short, action-first replies automatically. The original command is also available for someone who wants the full session-wide mode. [Upstream](https://github.com/ayghri/i-have-adhd/tree/1ecea1993b7fce257ffbd686c070948b5e07eda6)
- The **kinetic-type** starter comes from HyperFrames commit `8c31cb3f400b20710ff76fda53354d7abfd6faca`. This edition replaces the remote presenter footage with a silent colour field. The Apache 2.0 license is beside the composition. The pilot is a local render of this adaptation. [Upstream](https://github.com/heygen-com/hyperframes/tree/8c31cb3f400b20710ff76fda53354d7abfd6faca/registry/examples/kinetic-type)
- The **paper-film-starter** is the reusable paper-film project from the original workspace. Its folder includes the demo, renderer, example cutouts, asset credits and font licenses.
- The [direction guide](.claude/skills/direct-video/references/directions.md) links to the creators' previews. The [production guide](.claude/skills/direct-video/references/production.md) links to the other tools and individual recipes used on demand.
