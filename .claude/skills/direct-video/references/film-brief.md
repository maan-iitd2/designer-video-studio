# Film brief

Keep this short. Expand only the rows the film uses. Update at creative decisions and after paid work.

**Film and delivery** — subject, intended viewer, takeaway, platform, aspect, length, deadline if any.  
**Creative direction** — approved look, reference links or local paths, the detail to borrow, anything to avoid.  
**Words and sound** — script owner, exact script or path, language, narration/music/silent, key timed cues.  
**Build** — chosen starter or renderer, version, working folder, preview/export commands.

| Beat and time | Exact words or audio cue | What we see | Asset ID and move |
|---|---|---|---|

| Asset ID and purpose | Supplied / source / create / omit | File or source link | Permission, credit or reference only |
|---|---|---|---|

**Costs** — budget if supplied, API or subscription, usage baseline if available, actual paid total, outstanding commitments, remaining budget if applicable, next high estimate. Where helpful, ask for a single usage readout at the pilot. With an unknown API total, label remaining cash as unknown.

| Stage or vendor | Metered actual / estimate / included in plan | Amount or usage | Evidence, pending commitment or settled |
|---|---|---|---|

**Last accepted** — storyboard/pilot/export link and the decision.  
**Next** — one action or open question.  
**Delivery** — final MP4, editable project, asset credits, quality check, outstanding limits.
